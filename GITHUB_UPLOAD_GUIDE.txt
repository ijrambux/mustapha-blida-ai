   دليل رفع Mustapha Blida AI على GitHub
   GitHub Upload Guide for Mustapha Blida AI
═══════════════════════════════════════════════════════════════

📌 الخطوة 1: إنشاء حساب GitHub (إذا لم يكن لديك)
─────────────────────────────────────────────────
1. اذهب إلى: https://github.com/signup
2. سجل حساب جديد باستخدام بريدك الإلكتروني
3. أكد بريدك الإلكتروني

📌 الخطوة 2: إنشاء Repository جديد
─────────────────────────────────────────────────
1. اضغط على الزر الأخضر (+) في الأعلى → New repository
2. اسم المستودع: mustapha-blida-ai
3. الوصف: مولد فيديوهات قصيرة بالذكاء الاصطناعي | AI Short Video Generator
4. اختر: Public (عام) أو Private (خاص)
5. ✓ أضف README.md (اختياري)
6. ✓ أضف .gitignore → اختر Python
7. ✓ أضف License → اختر MIT License
8. اضغط Create repository

📌 الخطوة 3: رفع الملفات
─────────────────────────────────────────────────
# الطريقة 1: عبر سطر الأوامر (Git)

# 1. افتح Terminal / Command Prompt
cd ~/Desktop

# 2. استنسخ المستودع
git clone https://github.com/YOUR_USERNAME/mustapha-blida-ai.git
cd mustapha-blida-ai

# 3. انسخ ملفات المشروع إلى المجلد
# (انسخ جميع الملفات التي تم إنشاؤها)

# 4. أضف الملفات
git add .

# 5. ارتكب التغييرات
git commit -m "🎬 Initial release: Mustapha Blida AI v1.0.0"

# 6. ادفع إلى GitHub
git push origin main

─────────────────────────────────────────────────
# الطريقة 2: عبر واجهة الويب (أسهل)
─────────────────────────────────────────────────
1. افتح مستودعك على GitHub
2. اضغط على زر "Add file" → "Upload files"
3. اسحب وأفلت جميع ملفات المشروع
4. اكتب رسالة الارتكاب: "🎬 Initial release"
5. اضغط "Commit changes"

📌 الخطوة 4: إضافة رابط X في البروفايل
─────────────────────────────────────────────────
1. اذهب إلى ملفك الشخصي على GitHub
2. اضغط "Edit profile"
3. في حقل "Social accounts" أضف:
   - X (Twitter): https://x.com/mouse0000000
4. احفظ التغييرات

📌 الخطوة 5: تخصيص المستودع
─────────────────────────────────────────────────
1. اذهب إلى Settings → General
2. أضف Topics: ai, video-generator, python, openai, tiktok
3. أضف Website: https://x.com/mouse0000000
4. احفظ التغييرات

📌 الخطوة 6: إنشاء Release
─────────────────────────────────────────────────
1. اذهب إلى "Releases" في الجانب الأيمن
2. اضغط "Create a new release"
3. اختر "Choose a tag" → اكتب "v1.0.0"
4. عنوان الإصدار: "🎬 Mustapha Blida AI v1.0.0"
5. الوصف: انسخ محتوى README.md
6. اضغط "Publish release"

📌 الخطوة 7: مشاركة المشروع
─────────────────────────────────────────────────
1. انسخ رابط المستودع
2. شاركه على X مع وسم #AI #VideoGenerator
3. أضف صورة GIF للمعاينة (اختياري)
